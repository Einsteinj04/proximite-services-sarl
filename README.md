# Proximite Services SARL

A responsive travel services platform built with **Next.js**, allowing users to browse and book flights, hotels, and car rentals.

## 🚀 Live Demo
🔗 https://proximite-services-sarl.vercel.app/ 

## 📌 Features
- Responsive multi-page travel interface
- Navigation for flights, hotels, and car rental options
- Server-Side Rendering (SSR) for improved performance
- Reusable layout and UI components
- Modern UI/UX design

## 💻 Tech Stack
- Next.js  
- React  
- Tailwind CSS  
- HTML5 & CSS3


## 🛠 Installation

```sh
git clone https://github.com/Einsteinj04/proximite-services-sarl.git
cd proximite-services-sarl
